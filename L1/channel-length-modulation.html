What you are seeing

Once VDS passes VDS,sat the channel pinches off. The excess voltage VDS − VDS,sat is dropped across a depleted gap ΔL next to the drain, and that gap widens as the drain voltage rises — exactly as any reverse-biased depletion region does. The inverted channel that actually sets the current is now L′ = L − ΔL, so

ID = ID,sat · L / (L − ΔL) ≈ ID,sat(1 + λCLMVDS)

The same ΔL is a bigger fraction of a short channel, so the output curves tilt more as L falls. For a circuit this is a finite output resistance ro, and the best voltage gain a single transistor can give, gmro, falls with it.

Notation: λCLM is the circuit parameter (V⁻¹). It has nothing to do with the natural length λ of Animation 2.

Try this in class

  1. L = 1 µm, VGS = 1.2 V. Sweep VDS from 0 to 3 V and watch the pinch-off point leave the drain once VDS > 0.7 V.
  2. Read ΔL and the current increase at 3 V. Then set L = 0.25 µm and repeat: same ΔL, much larger fractional change.
  3. Note how the tangent's intercept −VA (Early voltage) moves toward the origin, and read the intrinsic gain.
  4. Raise the body doping: the gap shrinks (narrower depletion) and the gain recovers. Ask what this does to the threshold and to the junction capacitance.

Check yourself

Why is CLM mainly an analogue concern?A digital gate only needs the device to switch hard; a few percent more current in saturation barely matters. An amplifier's gain is gmro, and ro = 1/(λCLMID) is set directly by CLM. In short channels DIBL adds to the output conductance too.
An analogue designer wants gmro ≥ 50 at Vov = 0.2 V. Roughly what VA does that need?For a square-law device gmro = 2VA/Vov, so VA ≥ 50 × 0.2/2 = 5 V. That is why analogue blocks use longer-than-minimum channels.
Does the electron current really flow through a "depleted" region?Yes. Depleted means the electron density is small compared with the doping, not zero. The electrons crossing the gap move fast in its high field, so a small density carries the full current.

The model behind it

Square law with VT = 0.5 V, μnCox = 200 µA/V² and W = 5 µm, using the effective length L′ = L − ΔL in saturation. The gap width uses the depletion approximation with a small offset φ (0.5 V) that avoids an unphysical infinite slope at VDS,sat:

ΔL = √(2εSi/qNA) · [ √(φ + VDS − VDS,sat) − √φ ]

gm and ro are evaluated numerically at the operating point.

Long-channel picture: no DIBL, no velocity saturation. In real short devices the gap is two-dimensional and DIBL adds to the output conductance.
